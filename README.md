# Ledgerly — privacy policy and support

The two pages the App Store listing points at, served by GitHub Pages.

- [Privacy policy](https://nazmolla.github.io/ledgerly-privacy/)
- [Support](https://nazmolla.github.io/ledgerly-privacy/support.html)

Kept in its own repository rather than in the app's, because the app's is
private and these two pages have to be reachable by anybody — including a
reviewer who is not signed in.

Plain HTML with no build step and no external requests: the pages make the same
promise the app does, so loading a font or a script from somewhere else would be
a small lie on a page about not doing that.
